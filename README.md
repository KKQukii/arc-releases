# Arc

Installer and automatic updates for Arc, the on-device AI experience benchmark.

1. Open [**Releases**](https://github.com/KKQukii/arc-releases/releases/latest) and download **ArcBench-win-Setup.exe**.
2. Double-click it. Arc installs (no admin needed), adds **Arc** to the Start menu and opens.

Arc updates itself: each time it opens, it installs a newer version first if there is one.
